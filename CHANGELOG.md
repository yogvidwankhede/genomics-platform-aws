## [0.1.0] - initial platform

### Added
- **Pipeline (M1):** Nextflow DSL2 germline workflow: FastQC/fastp → BWA-MEM2 → GATK
  MarkDuplicates → GATK HaplotypeCaller or DeepVariant → bcftools norm/filter/stats → hap.py
  against GIAB → per-sample JSON summary → MultiQC. Pinned containers, nf-schema validation,
  profiles `test`, `benchmark`, `docker`, `awsbatch`, and nf-test module/pipeline suites.
- **Infrastructure (M2):** Terraform bootstrap (state bucket, GitHub OIDC roles) and modules
  `network`, `storage`, `ecr`, `iam`, `batch`, `trigger`, `observability`, composed by one
  `platform` root with dev/prod tfvars and separate state keys.
- **AWS execution path (M3 groundwork):** offline Nextflow head image, ECR mirroring of pinned
  images, AWS CLI staging for NAT-less Batch instances, and benchmark submission scripts.
- **Event-driven orchestration (M4):** S3 → EventBridge → Lambda → Batch submission,
  DynamoDB run registry, SNS notifications, queue watchdog, and a read-only FastAPI service.
- **CI/CD (M5):** GitHub Actions for ruff/pytest, nextflow lint/stub/nf-test, terraform
  fmt/validate/tflint/test, checkov, Trivy, OIDC `terraform plan` comments on PRs, and
  gated apply (dev automatic, prod behind Environment approval). pre-commit, CODEOWNERS,
  Dependabot, and release-please.
- **Operations and docs (M6):** CloudWatch dashboard and alarms (run failed, queue stuck,
  Lambda errors, DLQ, budget), JSON logs and EMF metrics, runbook (triage, resume, access,
  rollback, teardown), five ADRs, cost model, README and RESULTS.md (measured values only).

### Fixed
- DeepVariant calls were soft-filtered with a GATK-tuned `QUAL<30`; the filter default is now
  caller-specific.
